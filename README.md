# 會員集點 · 通用店家版

[開啟展示網站](https://hpppf7.github.io/member-points-demo/)

支援各行各業，自訂店家名稱、每點消費金額、兌換門檻與獎勵文字。
每次可選擇金額換點或直接輸入點數，核對確認後才入帳。

- 會員查詢：三個數字框輸入末三碼，不論找到幾位都要選擇確認。
- 新會員註冊：完整 09 開頭的 10 碼手機，確認後才建立。
- 範例 321：18 點；範例 678：兩位會員供核對。
- 展示版的會員、點數及設定皆在此頁暫存，重新整理即重置。請使用範例號碼。
