# 會員集點 · 分頁操作版

[開啟展示網站](https://hpppf7.github.io/member-points-demo/) · [下載 Android App](https://github.com/hPPPf7/member-points-demo/releases/latest)

支援各行各業，自訂店家、集點規則與獎勵內容。

## 操作方式

- 首頁輸入手機末三碼，再核對完整手機並點選會員；即使只找到一位也要選擇。
- 範例 `321`：18 點；`678`：兩位會員供選擇。
- 選擇「新增點數」，同頁切換金額換點或輸入點數，直接填寫並查看結果；核對後才入帳，返回修改保留草稿。
- 「新會員」需輸入完整手機並確認建立，不會自動註冊。
- 首頁右上「更多功能」→「集點設定」，空間足夠時同頁設定多個欄位，小螢幕則自動分頁，核對後確認儲存。
- 每個操作各自一頁；長內容與清單依空間和字體大小分頁，使用上一頁／下一頁操作。
- 大字體不強制縮小，確認操作只在內容最後一頁出現。

網站展示資料與設定只在當頁暫存，重新整理即重置，請使用範例電話。
Android 版在本機儲存，可離線與備份還原；不同裝置不自動同步。
更新請先備份，再直接覆蓋安裝，不要先解除安裝。

## App 更新（1.3 起）

先下載 1.3.0 並直接覆蓋安裝一次。之後開啟 App 會檢查新版本，回到首頁才顯示提示；也可從「更多功能 → 檢查更新」手動操作。

選擇下載後，由 App 驗證檔案與簽章，再交給 Android 確認安裝。首次可能需允許此 App 安裝更新，返回後再按安裝。沒網路仍可正常集點，會員資料不會上傳。

## 網站模擬與下載

網站右上角可直接下載 Android APK，會讀取更新資訊取得新版連結。使用手機／平板切換及旋轉按鈕可調整模擬外框，切換時保留當頁試用資料。


## 易讀版畫面（1.3.3）

網站外框不再將整個畫面縮小，改依可用尺寸排版；手機與平板的文字、輸入框及按鈕同步放大，按鈕緊接內容。可按「展開操作」增加空間；手機網站從「裝置」開啟切換選項。會員頁右上角時鐘圖示可查看最近紀錄。
