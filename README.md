## 快速操作

- 平常輸入手機末三碼查詢；只有一位符合就直接載入，多位符合時核對完整號碼後選擇。
- 輸入 321：直接找到 0987 654 321（18 點）。
- 輸入 678：選擇 0912 345 678（5 點）或 0999 000 678（3 點）。
- 新會員註冊才填完整 09 開頭的 10 碼手機；核對後確認才建立，不會自動註冊。
